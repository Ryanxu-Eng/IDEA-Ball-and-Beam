# IDEA Ball & Beam

An educational engineering project by the **IDEA Engineering Club** in Nanjing No.1 High School, based on the original [Balance Beam Kit](https://github.com/careyi3/balance_beam_kit) by careyi3.

This project explores feedback control systems through hands-on mechanical design, electronics, sensor, and Arduino programming.

## Project Resources

- `cad/` – Mechanical design files
- `code/arduino/` – Arduino source code
- `docs/` – Project documentation
- `electronics/` – Electronics and wiring resources

For the original project documentation, visit the [Balance Beam Kit website](https://careyi3.github.io/balance_beam_kit/).

## IDEA Engineering Club

The IDEA Engineering Club is building and testing this system as a hands-on engineering project.

We will document our assembly process, experiments, educational materials, and further improvements to the original design.

## Project Status

In progress – Hardware assembly, testing, and development.
